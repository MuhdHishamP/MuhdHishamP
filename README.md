# 👨‍💻 Muhammed Hisham

**`Product Engineer (Full Stack)`**

I'm a product engineer with 3 years of experience taking products from an empty repo to production. I work across the whole stack and most of what I build now has an LLM somewhere in the middle: agent pipelines, chat-driven interfaces, and the plumbing that makes them reliable enough to ship.
